# Monster Rolodex

Educational React application for fetching, displaying and filtering data.

## Technologies

- React
- JavaScript
- Fetch API
- CSS
- JSONPlaceholder API

## Features

- Fetches user data from an external REST API
- Displays reusable cards with names, email addresses and generated images
- Filters displayed cards dynamically from a search field
- Uses React state and effect hooks
- Demonstrates reusable component structure
